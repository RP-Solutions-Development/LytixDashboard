🎯 PARA USAR EN OTRO PROYECTO:

1. Lee: EXPORT_PROJECT_GUIDE.md (instrucciones paso-a-paso)

2. Archivos principales a copiar:
   - Dockerfile
   - docker-compose.yml
   - nginx.conf
   - .dockerignore
   - next.config.ts
   - tsconfig.json
   - lib/* (toda la carpeta)
   - scripts/* (toda la carpeta)

3. Instala dependencias:
   npm install mssql @tanstack/react-query zustand next-intl

4. Configura .env.local:
   SQLSERVER_HOST=tu_ip
   SQLSERVER_USER=tu_usuario
   SQLSERVER_PASSWORD=tu_contraseña

5. Crea tablas en SQL Server (ver EXPORT_PROJECT_GUIDE.md)

6. Test: bash scripts/run-tests.sh
